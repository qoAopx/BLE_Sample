# BLE Sample - RC Car Web Applications

## 概要 (Overview)
本プロジェクトは、WebブラウザからBluetooth Low Energy (BLE) を介してマイコン（ESP32など）と通信し、RCカーの走行データをリアルタイムで収集・活用するためのWebアプリケーション群です。
専用のネイティブアプリをインストールすることなく、ブラウザのみで「センサー情報の可視化（テレメトリー）」や「自動撮影付きのラップタイム計測（ラップタイマー）」といった高度な機能を実現します。
トップページの [`index.html`](index.html) から各アプリケーションへアクセスできます。

---

このリポジトリ（ディレクトリ）には、Web Bluetooth API (BLE) を利用して、ESP32などのマイコンから送信されたデータを受信・表示・処理するための2つのWebアプリケーションが含まれています。

## 1. テレメトリーアプリケーション (`telemetry.html`)

RCカーの各種センサーデータや走行データをリアルタイムで受信し、可視化するためのアプリケーションです。

### 主な機能

- **BLE接続機能**: ESP32等のデバイスとWeb Bluetooth API経由で接続 (`CONNECT` / `DISCONNECT` ボタン)。
- **データ可視化**: [p5.js](https://p5js.org/) を用いて、受信したデータを `canvas` 上にリアルタイムでグラフィカルに描画（描画ロジックは `sketch.js` に依存）。
- **データ記録・再生**: 受信したデータを記録 (`REC`) し、後から再生 (`PLAY`) する機能を備えています。
- **ステータス表示**: 現在の接続状態や、受信したデータ数を画面下部のフッターに表示します。

---

## 2. ラップタイマーアプリケーション (`laptimer.html`)

RCカーの周回ごとのラップタイムデータを受信し、カメラと連動して記録を残すためのラップタイマー専用アプリケーションです。

### 主な機能

- **BLE接続機能**: ESP32ベースのラップタイマー計測器と接続 (`CONNECT` / `DISCONNECT`)。
- **ラップタイム計測・表示**:
  - 受信したラップタイムを「現在のラップ (CURRENT LAP)」「ベストラップ (BEST LAP)」として大きく表示します。
  - 周回数 (LAPS) や 平均タイム (AVERAGE) も自動計算して表示します。
- **自動撮影機能 (START CAMERA)**:
  - 端末（スマホやPC）のカメラを起動し、ラップが記録された瞬間に自動で写真を撮影します。
  - 撮影された写真には「LAP番号」と「ラップタイム」がタイムスタンプとして印字され、自動でダウンロード保存されます。
  - 画面上にも写真の履歴 (`#photo-history`) として並べて表示されます。
- **履歴の表表示**: 計測された全ラップタイムをリスト形式（テーブル）で一覧表示します。
- **データのエクスポートと初期化**:
  - `COPY` ボタン: 全ラップタイム履歴をクリップボードにコピーして他のアプリへ共有可能。
  - `CLEAR` ボタン: 計測データや写真履歴をすべてリセットします。

※ 実際の通信ロジックおよびアプリケーションの動作は `sketch_laptimer.js` で制御されています。

## 技術スタック

- **HTML/CSS**: UI構築、レスポンシブなデザイン、ダークモードベースのスタイリング。
- **JavaScript (Vanilla)**: Web Bluetooth API, WebRTC (MediaDevices APIによるカメラ制御)。
- **p5.js**: `telemetry.html` でのグラフィック描画に使用。
